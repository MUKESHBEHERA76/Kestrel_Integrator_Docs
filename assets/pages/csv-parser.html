CSV Parser

CSV Parser turns delimited text into structured rows, or builds CSV text from structured data, inside the workflow runtime.

What it is

This connector does not require a database or external service. It reads a text payload or a document list and converts it into the format the next step needs.

Why it is useful

  • Ingest file content into row-level data.
  • Prepare data for validation or transformation.
  • Build CSV output for file export or downstream systems.

When you double-click it

Choose the mode and provide the matching fields:

  • mode - parse or build.
  • csvContent - string input used in parse mode.
  • docList - document list input used in build mode.
  • columnDelimiter, rowDelimiter, quoteChar, quoteAll - formatting options.
  • fields - array of field definitions used by the parser or builder.

Workflow input and output

  • Parse mode input - csvContent as a string.
  • Parse mode output - CsvList as an array of row documents.
  • Build mode input - docList as a document list or array.
  • Build mode output - csvString as a string, with outCSV as a fallback path.

Runtime notes

Match the delimiters and quote settings to the source file. If the data has headers, keep the field list aligned with the source column names so the resulting rows stay predictable.
