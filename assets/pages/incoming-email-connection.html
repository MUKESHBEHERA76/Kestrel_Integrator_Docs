Create an Email (IMAP/POP3) connection.

This project connection gives Email Trigger read access to a mailbox. Select IMAP for folder and read-state actions, or POP3 for INBOX polling and optional deletion.

Incoming protocols IMAP and POP3 retrieve mail. To send mail, create a separate Email (SMTP) connection.

Create

Connect an incoming mailbox

  1. 1
    Open the project

    Go to Projects → your project → Connections → Create Connection.

  2. 2
    Choose Email (IMAP/POP3)

    Name the connection, for example orders-inbox. Choose the protocol supported by your mail provider.

  3. 3
    Enter the mailbox details

    Provide server, TLS mode, port, username, password, and the folder to poll. Use INBOX for POP3.

  4. 4
    Test and save

    Run Test Connection to verify login and read-only folder access. Save and enable the connection, then select it in Email Trigger.

Verification

Test safely

Test Connection signs in and opens the selected folder read-only. It does not change, delete, or mark messages as read. A test success confirms access at that moment; the Email Trigger must also be configured and the workflow enabled to process messages.
