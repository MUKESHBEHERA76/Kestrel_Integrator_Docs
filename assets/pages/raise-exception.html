Raise Exception

Raise Exception stops the workflow on purpose and throws a controlled runtime error. It is the connector you use when the current payload should not continue.

What it is

The connector reads an error message from the pipeline and raises an exception with that text. It does not transform the payload or call an external system.

Why it is useful

  • Block invalid data before it reaches downstream systems.
  • Make business validation rules visible in the flow.
  • Force a failure branch when the workflow needs to stop immediately.

When you double-click it

Set the errorMessage field to a clear string that explains why the workflow stopped.

Workflow input and output

  • Input - errorMessage as a string.
  • Output - none; the step raises an exception and fails the run.

Runtime notes

This step should be used intentionally. The monitor view will show the message you provide, so keep it descriptive and actionable.
