Workflow / Connectors / Raise Exception

Raise Exception

Stop a workflow path with a deliberate runtime error that an Exception Handler can catch.

Pipeline input

Provide an errorMessage

Add Raise Exception from the Connector tab. Map a nonempty String to ${pipeline.input.errorMessage}, or set it in the step configuration. Pipeline variables in the message are substituted at runtime.

errorMessage = Order ${pipeline.input.orderId} is missing a customer ID.

Runtime behavior

Route the failure

The step throws the resolved message as a connector execution error. It has no normal Step Out value. Connect an Exception Handler to inspect the error document and return a controlled response. If the error remains unhandled, the run fails and pending JDBC work is rolled back. If a handler finishes the workflow successfully, the run is successful; design rollback requirements accordingly.
