Create an Email (SMTP) connection.

An SMTP connection holds the project’s outbound server, TLS mode, authentication, sender defaults, timeouts, and message size limit. The Send Email connector selects this connection and supplies message content at runtime.

Create

Set up a reusable sender

  1. 1
    Open the project

    Go to Projects → your project → Connections and choose Create Connection.

  2. 2
    Choose Email (SMTP)

    Give the connection a unique, descriptive name such as notifications-smtp.

  3. 3
    Enter provider details

    Use the SMTP host, port, TLS mode, credentials, and sender address supplied by the mail administrator. Do not use an IMAP or POP3 host for sending.

  4. 4
    Test and save

    Run Test Connection, correct any server or credential error, save, and keep the connection enabled so Send Email can use it.

Verification

Test transport, then test delivery

Test Connection checks handshake, TLS, and login without sending an email. If the UI offers Send Test Email, enter one recipient to check that the SMTP server accepts a message using Default From. SMTP acceptance does not guarantee delivery to the final mailbox.

i
In a workflow

Select this connection in Send Email, then map recipients, subject, body, and optional attachments in the step pipeline.

Troubleshooting

Check the server response

Connection timeouts usually indicate an unreachable host or blocked port. TLS or certificate failures require the correct security mode and a server certificate trusted by the runtime. Authentication failures require provider-approved credentials. A successful connection test with a failed send can indicate a rejected sender, recipient, size, or provider policy.
