Postgres

Postgres is the reusable PostgreSQL connection profile used by workflow SQL steps and the SQL Console. It keeps the database credentials in one project-scoped place.

What it is

The runtime uses this saved profile when a query step needs PostgreSQL access. It is not a one-off connection; it is meant to be reused by multiple workflows and console actions.

Why it is useful

  • Share one database definition across many assets.
  • Keep console usage aligned with the workflow runtime.
  • Reduce credential duplication in the project.

When you double-click it

Provide the standard PostgreSQL connection fields:

  • host - string server host.
  • port - number, usually 5432.
  • databaseName - string database name.
  • username - string login name.
  • password - string password.
  • schema - string schema, usually public.

Workflow and SQL Console usage

  • Query input - queryString as a single SQL statement string.
  • Returned rows - dbResponse as a serialized JSON string containing the result rows or update summary.
  • Row count - resultCount as a string value containing the row count.

Runtime notes

The runtime accepts only one SQL statement at a time. If you need to run multiple changes, split them into separate steps or use a workflow pattern that keeps the execution explicit.
