OracleDB

OracleDB is the reusable Oracle connection profile used by workflow SQL steps and the SQL Console. It keeps Oracle access details in a single project-scoped profile.

What it is

The runtime uses this enabled profile when a query step or console action needs Oracle access. The connector is meant to be reused across multiple assets.

Why it is useful

  • Centralize Oracle credentials and service details.
  • Reuse the same connector in workflows and the SQL Console.
  • Keep enterprise database access easier to manage.

When you double-click it

Provide the Oracle fields the runtime expects:

  • host - string server host.
  • port - number, usually 1521.
  • serviceName - string Oracle service name.
  • username - string login name.
  • password - string password.
  • schema - string schema, usually public.

Workflow and SQL Console usage

  • Query input - queryString as a single SQL statement string.
  • Returned rows - dbResponse as a serialized JSON string containing the result rows or update summary.
  • Row count - resultCount as a string value containing the row count.

Runtime notes

Oracle workflows can also set the current schema during runtime. The SQL runtime still enforces a single statement per execution.
