Administration / Platform Settings

Configure server-wide behavior.

Platform Settings applies across projects. Administrators can change settings without restarting the server.

Connection health check interval

Open Administration → Platform Settings. Search for Connection health check interval, enter a whole number from 1 to 1440 minutes, and select Save. The default is 5 minutes. Enabled project connections are checked on this schedule; disabled connections are skipped. Changes affect the next check.

Setting: connection.health.check.interval.minutes
Example value: 10
Result: enabled project connections are checked about every 10 minutes

The Info button explains the setting. Values outside 1–1440 or non-integers are rejected. Saving requires Administrator access.

Advanced diagnosis

Turn on Advanced diagnosis when investigating an API issue, then select Download report. The JSON report includes up to the latest 2,000 API operations on that server instance; request bodies, query strings, and credentials are excluded. Turn it off after investigation to stop collecting new diagnostic events.

Setting: diagnostics.advanced.enabled
Example: true
Download: kestrel-diagnosis.json

A report from one server is not a cluster-wide report. If the download or save fails, the page displays the server error. See Runtime Operations for live worker and dependency status.
