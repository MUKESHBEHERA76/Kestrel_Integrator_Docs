Projects / XSLT Alias

Store a reusable XSLT stylesheet

An XSLT Alias is a named stylesheet saved with a project. A workflow XSLT transformer selects the alias and applies its XSLT to an XML String at runtime.

Setup

Create the alias in a project

  1. 1
    Open XSLT Alias

    Go to Projects → your project → XSLT Alias → Create XSLT Alias.

  2. 2
    Enter metadata

    Set Alias name, for example OrderToPurchaseOrder, optional File name order-to-purchase-order.xslt, and optional Comment describing its use. The name must be unique among aliases.

  3. 3
    Supply the stylesheet

    Upload an .xsl or .xslt file. Review the XSLT source in the editor. The stylesheet body is required; the file name alone does not contain transformation logic.

  4. 4
    Save and select it

    Create the alias. It appears in the current project's XSLT Alias list and in the XSLT transformer dropdown for that project. Save the workflow after selecting it.

Worked example

Convert an order to a purchase order

Save the following stylesheet under alias OrderToPurchaseOrder:

<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="2.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
  <xsl:output method="xml" indent="yes"/>
  <xsl:template match="/order">
    <purchaseOrder>
      <orderNumber><xsl:value-of select="id"/></orderNumber>
      <amount><xsl:value-of select="total"/></amount>
    </purchaseOrder>
  </xsl:template>
</xsl:stylesheet>

Given this XML input:

<order><id>ORD-1042</id><total>89.50</total></order>

The transformer returns XML equivalent to:

<purchaseOrder><orderNumber>ORD-1042</orderNumber><amount>89.50</amount></purchaseOrder>

XML formatting and declaration may differ; downstream steps should consume the XML structure. The XSLT transformer guide shows the exact pipeline mapping.

Maintenance

Understand reuse and updates

An alias keeps stylesheet source and metadata in one project resource; multiple workflows can select it. Editing its XSLT changes future transformations that resolve that alias. Test dependent workflows after changing it. Kestrel blocks deletion while a workflow still references the alias. An alias from another ordinary project is not selectable in the current project.

Runtime rejects an empty stylesheet, malformed XSLT, inaccessible aliases, and source XML that cannot be parsed. External stylesheet includes and external protocol access are disabled. Keep the stylesheet below 1 MiB; the transformer also limits input XML to 5 MiB.
