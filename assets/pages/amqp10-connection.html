Projects / Connections / AMQP 1.0

Connect to an AMQP 1.0 endpoint.

Create a project AMQP 1.0 connection for the AMQP 1.0 Trigger or AMQP 1.0 workflow connector. This uses AMQP 1.0 and a broker-defined source address, not RabbitMQ's AMQP 0-9-1 protocol.

↔

Check the protocol A broker product may offer both protocols on different listeners. Choose the connection that matches the listener you were given.

Before you begin

Get endpoint and address details

Obtain the AMQP 1.0 hostname, listener port, transport (TCP or WebSocket), TLS requirement, authentication details, and the exact existing source address. Some providers also require a Virtual/Open hostname, such as a Solace Message VPN. Import a trusted certificate or client key pair in Security → Keystore before configuring TLS or client-certificate authentication. Kestrel does not provision the broker destination.

Create

Configure the project connection

  1. 1
    Choose AMQP 1.0

    Open Projects → your project → Connections → Create Connection and choose AMQP 1.0. Name the connection for the broker or environment.

  2. 2
    Enter endpoint details

    Select Generic, Solace PubSub+, Red Hat AMQ/Artemis, Azure Service Bus, RabbitMQ 4+, Apache Qpid, or Custom profile. Choose TCP or WebSocket. Enter Host, Port, optional Virtual/Open hostname, Container ID, and optional failover endpoints.

  3. 3
    Configure security

    Select TLS and a trusted certificate alias where required. Choose Anonymous, SASL PLAIN, SASL EXTERNAL, or OAuth 2.0 client credentials according to broker policy. EXTERNAL also needs a client key-pair alias. Supply the fields displayed for the chosen method.

  4. 4
    Review session settings

    Set idle timeout, maximum frame size, connection timeout, and reconnect delay in milliseconds. Use broker-approved values when its limits differ from the defaults.

  5. 5
    Test and save

    Click Test Connection, then save and enable it. The test opens an AMQP 1.0 connection and checks protocol negotiation and authentication. It does not verify a later trigger source address or permission to consume it.
