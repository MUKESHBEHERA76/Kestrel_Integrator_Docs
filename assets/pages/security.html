Security

Manage reusable secrets, keys, and inbound authentication.

Security holds application-wide assets that workflows and project connections reference by alias. Configure the asset once, then select it where the integration needs it.

Security CredentialsKeystore
🔒

Three separate roles. Security Credentials store integration credentials; Keystore manages keys and certificates; Webhook Auth protects incoming Webhook Triggers.
