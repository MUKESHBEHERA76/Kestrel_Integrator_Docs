Project model

Projects

A project is the workspace boundary in Kestrel Integrator. Everything you create, reuse, run, and monitor is grouped inside that project context, so workflows, services, connections, APIs, data structures, XSLT aliases, and schedulers stay together.

What is a project?

01

In this app, the selected project controls what the workspace shows. Pick a project once, then use the nested menu on the left to jump into the detailed topics that belong to that project.

A project is not just a folder name. It is the context that binds together the integration assets, runtime configuration, and reusable building blocks for one solution.
