Projects

A project is the package that holds the integration pieces you build in Kestrel Integrator. It is the container where your workflows, reusable services, connections, APIs, data structures, XSLT aliases, and schedulers live together for one business solution.

What is a project?

01

In this app, a project is the boundary for everything you want to build, reuse, run, and monitor. When you select a project, all the available assets shown in the workspace belong to that project context.

What lives inside a project?

02
Workflow The orchestration flow that connects steps, mappings, and runtime logic.
Reusable services Shared flows you can call from multiple workflows instead of rebuilding logic again.
API The project-scoped interface that exposes or consumes business data through endpoints.
Connections Reusable database or security connectors that workflows, services, and consoles can use.
Data Structure The project-specific input, output, and document shapes used in mappings and steps.
XSLT Alias Reusable XSLT shortcut names or aliases used to support transformation work inside the project.
Schedluer The timing setup that runs a project workflow automatically based on the configured schedule.
