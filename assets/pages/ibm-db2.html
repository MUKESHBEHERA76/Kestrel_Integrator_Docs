IBMDB2

IBMDB2 is the reusable Db2 connection profile used by workflow SQL steps and the SQL Console. It keeps the enterprise database settings in one project-scoped profile.

What it is

The runtime uses this enabled profile when a query step or console action needs Db2 access. The connector is designed to be shared across many assets.

Why it is useful

  • Centralize Db2 credentials and schema information.
  • Reuse the same connector in workflows and the SQL Console.
  • Keep enterprise database access easier to audit and control.

When you double-click it

Provide the Db2 fields the runtime expects:

  • host - string server host.
  • port - number, usually 50000.
  • databaseName - string database name.
  • username - string login name.
  • password - string password.
  • schema - string schema.

Workflow and SQL Console usage

  • Query input - queryString as a single SQL statement string.
  • Returned rows - dbResponse as a serialized JSON string containing the result rows or update summary.
  • Row count - resultCount as a string value containing the row count.

Runtime notes

The Db2 runtime handles enterprise data carefully, including large values and binary content. The SQL execution still allows only one statement at a time.
