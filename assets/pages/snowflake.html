Snowflake

Snowflake is the reusable connection profile for Snowflake-backed workflows and SQL Console runs. The project stores the account and authentication details once, then reuses them anywhere they are needed.

What it is

This connection keeps the Snowflake account details outside the workflow logic. The runtime only needs the enabled profile when a step or console action runs a query.

Why it is useful

  • Reuse the same Snowflake profile across many workflows.
  • Keep account details and credentials centralized in the project.
  • Use the same profile in the workflow SQL step and the SQL Console.

When you double-click it

Provide the Snowflake account and authentication details the runtime needs:

  • accountIdentifier - string Snowflake account identifier.
  • authenticationType - string, such as basic or key-pair.
  • username - string user name.
  • password - string password when basic auth is used.
  • privateKey and passphrase - key-pair auth values when that mode is selected.
  • warehouse - string warehouse name.
  • databaseName - string database name.
  • role - string role name.
  • schema - string schema name.

Workflow and SQL Console usage

  • Query input - queryString as a single SQL statement string.
  • Returned rows - dbResponse as a serialized JSON string that contains the row list.
  • Row count - resultCount as a string value containing the row count.

Runtime notes

Only enabled Snowflake connections should appear in runtime selection lists. The SQL runtime enforces a single statement at a time, so the query input should not contain multiple statements separated by semicolons.
