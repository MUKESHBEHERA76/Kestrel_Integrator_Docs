Create a Oracle Database connection

Save the JDBC endpoint and a User Credentials alias in the project, then select this enabled connection in the Oracle Database workflow connector.

Setup

Create and test the connection

  1. 1
    Create a credential

    In Security → Security Credentials, create a User Credentials entry such as oracle_db_app_user with a database login and password. Give that login access to the database, schema, and tables the workflow will use.

  2. 2
    Open the project connection form

    Choose Projects → your project → Connections → Create Connection → Oracle Database. Enter a unique name such as oracle_db_orders.

  3. 3
    Enter endpoint details

    Use the example below as a guide and replace it with your server details. Select the User Credentials alias; do not put a password in Other JDBC properties.

  4. 4
    Test and save

    Click Test connection, resolve any host, authentication, database, or schema error, then save and enable the connection. A successful test proves the configured JDBC session opens; it does not prove every later SQL statement has permission.

JDBC options

Add driver properties when required

Use Other JDBC properties → Add property to enter driver-specific name/value pairs required by your environment, for example a supported timeout or TLS setting. Names must be unique; the form rejects invalid or protected credential names. Confirm each property against your JDBC driver configuration and retest the connection after changing it. The credential alias remains the source of the username and password.

Existing connections created with embedded credentials can continue to work, but select a User Credentials alias when editing them to centralize secret management.
