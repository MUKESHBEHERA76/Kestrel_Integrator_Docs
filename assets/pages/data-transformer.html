Data Transformer

Data Transformer is the workflow mapping step used to reshape payload data before the next connector consumes it. It is the visual place where source paths are mapped to target paths.

What it is

This step works on pipeline data directly. It does not call an external system. Instead, it lets you copy, move, rename, combine, or normalize fields inside the current message.

Why it is useful

  • Prepare request payloads for APIs, services, or database steps.
  • Normalize field names and data types before downstream use.
  • Keep mapping logic visible instead of hiding it inside code.

When you double-click it

Open the mapping editor and define the source and target paths you want to use. The runtime stores the mapping operations in an operations array.

Workflow input and output

  • Input - pipeline objects, documents, strings, numbers, or lists depending on the mapping.
  • Output - a transformed object or document written back into the selected target path.

Runtime notes

Keep each path explicit so the mapping stays readable. This step is often used before Send HttpResponse, reusable services, or database connectors.
