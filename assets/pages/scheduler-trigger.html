Workflow triggers / Scheduler

Start a workflow on a UTC schedule.

Scheduler Trigger starts an enabled workflow when its cron expression fires. Define the schedule in the workflow editor, then enable the scheduler separately from the workflow in the project's Schedulers page.

Workflow design

Create and activate a scheduled workflow

  1. 1
    Add the trigger

    Open Projects → your project → Workflows, create or edit a workflow, and drag Scheduler Trigger from Workflow triggers onto the canvas. Connect it to the first executable step. A workflow can have only one trigger.

  2. 2
    Set the cron expression

    Double-click Scheduler Trigger and enter a five- or six-field cron expression. The initial value is */5 * * * *, meaning every five minutes. Add an optional comment to explain the business schedule, such as Import orders every weekday morning.

  3. 3
    Save and enable the workflow

    Save the topology and enable the workflow. The scheduler cannot be enabled while the workflow is disabled.

  4. 4
    Enable the scheduler

    Open Projects → your project → Schedulers. Find the workflow and click Enable scheduler. A Developer or Administrator can manage scheduler state, subject to the workflow edit lock. An invalid cron expression is rejected when enabling.

  5. 5
    Check the next run

    Refresh the Schedulers page. Confirm the card shows Enabled, Workflow: Enabled, Cron valid, and a Next run (UTC) time.

To pause future scheduled runs without deleting the workflow, select Disable scheduler. Disabling the workflow also prevents its scheduler from firing.

Syntax

Read the expression in UTC

Kestrel parses cron using Spring's cron syntax. It accepts six fields in this order:

second minute hour day-of-month month day-of-week

For convenience, Kestrel also accepts five fields, minute hour day-of-month month day-of-week, and prepends 0 as the seconds field. Thus */5 * * * * is equivalent to 0 */5 * * * *. All schedules and next-run calculations use UTC, regardless of the browser's local time zone.

SymbolMeaningExample
*Every allowed value* in month means every month.
*/nEvery n units*/5 in minute means every five minutes.
a-bInclusive rangeMON-FRI means weekdays.
a,bList of values9,17 in hour means 09:00 and 17:00 UTC.

Use a six-field expression when you need to specify seconds explicitly. Use the Next run value to confirm the expression produces the intended UTC time before enabling a production workflow.

Examples

Common cron schedules

ExpressionWhen it fires (UTC)Possible use
*/5 * * * *Every five minutes, at second 0Frequent polling or small batch intake.
0 */15 * * * *Every fifteen minutes, at second 0Quarter-hour reconciliation.
0 0 * * * *At the start of every hourHourly synchronization.
0 30 9 * * MON-FRI09:30, Monday through FridayWeekday business report.
0 0 0 * * *00:00 each dayDaily data rollover.
0 0 6 1 * *06:00 on the first day of every monthMonthly statement preparation.
0 0 9,17 * * MON-FRI09:00 and 17:00 on weekdaysTwice-daily business-day import.

Example: for a team working in India Standard Time (UTC+05:30), 0 30 3 * * MON-FRI fires at 09:00 IST on weekdays. The schedule remains defined in UTC; adjust the expression if the business region observes daylight saving time.

Execution

What happens at the scheduled time

When the cron fires, Kestrel checks that the workflow and scheduler are still enabled, coordinates the fire across application instances, and admits a durable workflow run. The trigger starts with an empty external input document; build the data needed by later steps in the workflow itself. The run's system trigger is SCHEDULER.

The Schedulers page lists the workflow name and version, cron expression, comment, validation status, and Next run (UTC). Use workflow execution analytics to inspect admitted runs. A scheduler admission failure before a run exists is written to backend application logs.

When no run appears

SymptomCheck
Enable scheduler does not succeedEnable the workflow first, confirm the cron is valid, and make sure you have a Developer or Administrator role and the required workflow edit lock.
Scheduler shows DisabledClick Enable scheduler in the project's Schedulers page. Saving the trigger does not turn this switch on.
Next run shows Not scheduledCheck both enabled states and cron validity. Refresh the page after saving or toggling.
Runs appear at an unexpected hourCron uses UTC. Compare the displayed Next run (UTC) with the target business time zone.
