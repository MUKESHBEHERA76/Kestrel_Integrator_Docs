Pipeline Logger

Record a formatted snapshot of the current pipeline in the workflow run log.

Configuration

Place the step where inspection is needed

Add Pipeline Logger after the step you want to inspect. No external connection or explicit Step In mapping is required. The runtime serializes the current input, output, temporary, system, and error sections as formatted JSON.

{"input":{"orderId":"ORD-1042"},"output":{"status":"accepted"},"temp":{},"system":{},"error":{}}

Runtime output

Read the log entry

The snapshot is written as an INFO entry in the workflow run log. It is not a new Step Out document. Values named contentBase64 are replaced with [binary content omitted] in this log view; the actual pipeline data remains available to subsequent steps. Other sensitive values can still appear, so use this connector judiciously in production.
