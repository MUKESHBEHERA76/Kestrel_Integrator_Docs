Pipeline Logger

Pipeline Logger captures the full pipeline snapshot at runtime. It is the fastest way to see what data existed in the workflow when a step ran.

What it is

The connector reads the current pipeline state and returns it as a pretty-printed JSON string. It does not depend on an external connection.

Why it is useful

  • Inspect input and output shapes after a run.
  • Debug mapping issues without adding custom code.
  • Help support teams understand what happened during execution.

When you double-click it

There is no external configuration. The connector is already set to log the current pipeline snapshot.

Workflow input and output

  • Input - the implicit pipeline snapshot.
  • Output - a formatted JSON string of the pipeline state.

Runtime notes

Use this step when you need to see the full message structure, but avoid logging sensitive data unless the environment is safe for it.
