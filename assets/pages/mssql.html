MSSQL

MSSQL is the reusable Microsoft SQL Server connection profile used by workflows and the SQL Console. It lets the project talk to SQL Server without hard-coding credentials in the flow.

What it is

The runtime uses this profile when a query step or console action needs SQL Server access. The saved connection can be reused anywhere in the project.

Why it is useful

  • Keep SQL Server credentials centralized.
  • Reuse the same connection across workflows and console runs.
  • Make database access easier to audit and enable or disable.

When you double-click it

Provide the SQL Server fields the runtime expects:

  • host - string server host.
  • port - number, usually 1433.
  • databaseName - string database name.
  • username - string login name.
  • password - string password.

Workflow and SQL Console usage

  • Query input - queryString as a single SQL statement string.
  • Returned rows - dbResponse as a serialized JSON string containing the result rows or update summary.
  • Row count - resultCount as a string value containing the row count.

Runtime notes

The SQL runtime blocks multi-statement execution. Keep the query to one statement and let the workflow decide how to handle the result.
