Logger

Write a selected message to the workflow run log without changing the pipeline.

Configuration

Choose level and message

Logger is a workflow step. Set the level, for example INFO, WARN, or ERROR. Map ${pipeline.input.logMessage} in Settings or enter a message with pipeline substitutions in the step configuration. The runtime uses the mapped message first; if it is empty it falls back to configured text, comment, or step label.

level = INFO
logMessage = Received order ${pipeline.input.orderId}

Output

Inspect the run log

Logger has no business payload output. The entry appears in workflow execution logs with the selected severity and step. Log identifiers and state changes rather than passwords, tokens, or full personal data. For the full pipeline shape, use Pipeline Logger.
