Workflow End

Workflow End marks the terminal point of a flow. It does not transform data; it simply makes the execution path explicit and tells readers where the workflow stops.

What it is

This connector is a terminal step. In the Kestrel runtime it is used when the flow has finished all required processing and no further mapping is needed.

Why it is useful

  • Show where a workflow intentionally ends.
  • Keep the flow diagram easy to read for developers and reviewers.
  • Separate the main business logic from the final stop point.

When you double-click it

There are no runtime fields to configure. The step is a marker, so the user only needs to place it where the workflow should stop.

Workflow input and output

  • Input - the current pipeline state at the end of the flow.
  • Output - no new payload; the workflow completes here.

Runtime notes

If you need to preserve or return data, do that before this step. Workflow End should remain the last stop in the diagram.
