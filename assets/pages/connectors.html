Connections and connectors

In Kestrel Integrator, a connection is a reusable profile that stores credentials and endpoint details. A connector is the runtime step or reusable profile that uses that configuration inside a workflow, service, or console action.

Reusable connection profiles

  • Snowflake - project-scoped database access for Snowflake accounts.
  • Postgres - reusable PostgreSQL profile for workflows and the SQL Console.
  • MSSQL - SQL Server profile that can be reused across runtime steps.
  • MySql - MySQL connection profile with project-level reuse.
  • MariaDB - MariaDB connection profile with project-level reuse.
  • OracleDB - Oracle profile using host, port, and service details.
  • IBMDB2 - Db2 profile for enterprise workflows and console runs.
  • PGP - reusable security profile that stores key material and passphrase details.

Workflow connectors

  • Logger - write runtime messages from pipeline values.
  • Data Transformer - reshape payloads before the next step.
  • Send HttpResponse - return the response for request-driven workflows.
  • Workflow End - mark the terminal point of the flow.
  • CSV Parser - parse or build CSV data.
  • Pipeline Logger - inspect the current pipeline snapshot.
  • XSLT Transformer - transform XML using a project alias.
  • Sleep - pause execution for a configured time.
  • Raise Exception - stop execution with a controlled error.
  • Multi Transformation - group several utilities or service calls into one step.
