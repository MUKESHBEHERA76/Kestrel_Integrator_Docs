How connectors work

Configure the step, then map its pipeline

Connector configuration contains stable design choices. The settings icon opens the pipeline where runtime inputs and outputs are mapped.

01Add a connector

Drag the required connector from the workflow palette onto the editor.

02Configure it

Double-click the step and select the connector-specific behavior.

03Map inputs

Use pipeline values, runtime variables, copied values, or deliberate hardcoded constants.

04Map outputs

Expose only the response values that downstream workflow steps require.
