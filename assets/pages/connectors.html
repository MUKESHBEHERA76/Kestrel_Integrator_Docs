Connections

Connections define reusable endpoints and credentials. The docs here explain how to create, enable, and reuse them across the app.

Connector catalog

01

Select the connector type first, then enter the required host, port, database, username, password, or security options.

Enabled state

02

Only enabled connections should appear in runtime features like the SQL Console or workflow runtime selection.

Reuse everywhere

03

One saved connection can be used in multiple workflows, services, and console actions without re-entering credentials.
