Create a Slack connection

Create one project connection for a Slack workspace, then select it from Slack workflow connector steps. The connection stores the Slack API endpoint, authentication mode, a bot or user OAuth token, optional workspace ID, and timeout. Message and channel values belong in each step's pipeline.

Before creating the connection

Prepare the Slack app and OAuth token

  1. 1
    Install a Slack app in the workspace

    Give the app only the OAuth scopes needed for the actions you plan to run. Install or reinstall it after changing scopes. For ordinary automation choose a bot token; choose a user token only when the Slack operation must run with that user's permitted access. Slack issues a token such as xoxb-… for a bot or xoxp-… for a user.

  2. 2
    Copy the OAuth token

    Copy the installed app's bot or user OAuth token from Slack. Enter it only in the Slack connection token field; do not paste it into a workflow field or a connection name.

  3. 3
    Know the workspace

    Optionally record its workspace ID, for example T0123456789. Kestrel can compare this with the identity returned by Slack during the connection test.

The connection stores the installed app's OAuth access token in encrypted configuration. Kestrel never returns its value through the connection API. To rotate a token, enter a replacement in Edit and run Test connection again. This form does not run an interactive OAuth installation or automatically refresh a rotated token.

Project setup

Create, test, and enable the connection

  1. 1
    Open the connection picker

    Go to Projects → your project → Connections → Create Connection. Choose Slack Connection. The plain Slack item belongs in the workflow editor's Connector tab.

  2. 2
    Set the endpoint

    Name it slack-operations-prod; choose https://slack.com/api, or the GovSlack URL if that is your environment.

  3. 3
    Choose token type and enter the token

    Select Bot OAuth token and paste a bot token beginning with xoxb- into the Bot OAuth token field. For user authentication, select User OAuth token and enter a xoxp- token. Enter workspace ID T0123456789 if you want the identity check. Set timeout to 30 seconds.

  4. 4
    Run Test connection

    The form requires a successful test for the current values before saving. Resolve any token, endpoint, or workspace mismatch error, then save and enable the connection.

  5. 5
    Use it from a workflow

    Add the Slack connector step and choose slack-operations-prod in its Connection dropdown. The selected connection must belong to the same project and remain enabled.

Verification and health

Understand what Test connection proves

Kestrel calls Slack's auth.test method with the saved token. It checks that Slack accepts the token and, when configured, that the returned workspace ID matches. A successful test can show a message such as Slack authentication succeeded for workspace T0123456789. It does not prove that the token has chat:write, channel management scopes, or membership in a particular conversation. Test an actual operation in a workflow to verify its permissions.

Enabled Slack connections also participate in Kestrel's periodic connection health checks. A disabled connection is not probed and cannot be used by the workflow step. The API endpoint and authentication settings are reused at runtime; the individual operation supplies its own request fields.

Troubleshooting

Diagnose connection failures

SymptomCheck
Token field is blank during EditThis is expected: saved tokens are never returned. Leave it blank to keep the current token, or enter a replacement and run Test connection.
Token type rejectedMatch Bot mode with xoxb- and User mode with xoxp-. Enter a replacement token in Edit if Slack revoked the old one.
Workspace mismatchCheck the optional workspace ID and that the token was issued for the intended installation.
Test succeeds, operation reports missing_scope or not_in_channelAdd the required Slack OAuth scope, reinstall the app, or add it to the target conversation. The connection test checks identity, not action permissions.
Rate limitSlack's Retry-After interval appears in the error. Delay and retry in the workflow with care, especially for operations that create or post data.
