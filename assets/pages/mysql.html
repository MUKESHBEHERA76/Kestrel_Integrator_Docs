MySql

MySql is the reusable MySQL connection profile used by workflow SQL steps and the SQL Console. It keeps the project connection details in one place so the runtime can reuse them safely.

What it is

The saved profile represents a project-scoped MySQL data source. The runtime only needs the enabled profile to execute a query.

Why it is useful

  • Reuse one MySQL profile across many workflows.
  • Keep SQL Console usage aligned with the same connection details.
  • Limit credential changes to one connector instead of many steps.

When you double-click it

Provide the MySQL fields the runtime expects:

  • host - string server host.
  • port - number, usually 3306.
  • databaseName - string database name.
  • username - string login name.
  • password - string password.
  • schema - string schema, usually public.

Workflow and SQL Console usage

  • Query input - queryString as a single SQL statement string.
  • Returned rows - dbResponse as a serialized JSON string containing the result rows or update details.
  • Row count - resultCount as a string value containing the row count.

Runtime notes

The runtime only allows one statement at a time. Keep the connector enabled if you want it to appear in runtime selection lists and in the SQL Console.
