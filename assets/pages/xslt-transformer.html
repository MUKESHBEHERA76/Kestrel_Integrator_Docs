XSLT Transformer

XSLT Transformer applies a project XSLT alias to XML data inside the workflow. It is the step you use when XML must be reshaped before the next connector consumes it.

What it is

The runtime reads XML input, finds the selected alias in the current project, and runs the transformation against that stylesheet. It does not need a database or HTTP connection.

Why it is useful

  • Convert XML into a different XML shape.
  • Reuse the same alias across many workflows.
  • Keep transformation rules stored inside the project instead of hard-coding them.

When you double-click it

Provide the alias and the source XML the runtime should transform:

  • aliasId / aliasName - the project XSLT alias to use.
  • inputXML - the XML string or XML payload to transform.

Workflow input and output

  • Input - inputXML as a string.
  • Output - transformedOutput as a string.

Runtime notes

Keep the alias name and XML source clear so the transformation is easy to follow in the workflow editor. The output is usually passed to the next step as XML or text.
