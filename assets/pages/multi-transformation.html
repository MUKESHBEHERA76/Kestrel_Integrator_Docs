Multi Transformation

Multi Transformation groups several utilities or service calls into one workflow step. It is the connector you use when a small chain of transformations should live inside a single visible block.

What it is

The runtime executes a list of inner items. Each item can be a utility or a project service call, and each item can have its own inputs, mappings, and outputs.

Why it is useful

  • Keep related logic together instead of scattering it across many steps.
  • Mix utilities and service calls in one place.
  • Make the workflow easier to scan when a transformation chain is short.

When you double-click it

Add the inner items you want the runtime to execute. The runtime expects the multiTransformation.items array to contain the full inner plan.

  • Utility item - provide utilityName, inputs, and outputMappings.
  • Service call item - provide serviceName, inputMappings, inputValues, and outputMappings.

Workflow input and output

  • Input - the values required by each inner item.
  • Output - a summary object with executedItems and an items array of runtime results.

Runtime notes

The runtime fails if the list is empty, so always add at least one utility or service call. This connector is powerful, but it works best when each inner mapping is documented clearly.
