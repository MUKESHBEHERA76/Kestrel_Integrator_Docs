PGP

PGP is the security connector used to encrypt, decrypt, sign, and verify payloads in a workflow. It uses a reusable PGP connection profile for the key material and exposes the security operation in the step editor.

What it is

The connection profile stores the reusable key details, and the workflow step selects the operation that should run. This keeps secret material out of the flow logic and makes security handling repeatable.

Why it is useful

  • Protect data before it leaves the project boundary.
  • Validate signed messages from partners or downstream systems.
  • Keep secure file exchange logic inside the workflow runtime.

When you double-click it

First select the reusable PGP connection, then choose the operation and map the matching payload field.

  • Connection profile - public key, private key, and optional passphrase values.
  • Operation - encrypt, decrypt, sign, or verify.
  • Algorithm - select_Algorithm, usually RSA.
  • Encrypt input - messageToEncrypt as a string.
  • Decrypt input - messageToDecrypt as a string.
  • Sign input - message as a string.
  • Verify input - signedMessage as a string.

Workflow input and output

  • Encrypt output - encryptedData as a string.
  • Decrypt output - decryptedData as a string.
  • Sign output - signedMessage as a string.
  • Verify output - verificationStatus as a string status value.

Runtime notes

Keep the message payload and key configuration aligned with the selected operation. Encrypt and sign depend on the private or public key setup provided by the connection profile.
