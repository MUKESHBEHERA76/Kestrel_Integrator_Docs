Sleep

Sleep pauses workflow execution for a configured duration. It is a simple timing connector that blocks the flow for a short, controlled period.

What it is

The connector waits for the number of seconds you provide, then lets the workflow continue. It does not call any external system and it does not produce a payload.

Why it is useful

  • Wait before a retry or polling cycle.
  • Space out request bursts in a flow.
  • Test delayed execution behavior in a controlled way.

When you double-click it

Set the sleepTime field as a non-negative number of seconds.

Workflow input and output

  • Input - sleepTime as a number.
  • Output - none; the step only delays the flow.

Runtime notes

Keep the delay short and intentional so the workflow remains responsive and easy to reason about.
