Sleep

Pause the current workflow execution for a configured number of seconds. The step does not call an external system.

Pipeline input

Map sleepTime

Add Sleep in the Connector tab. In Settings, map or set ${pipeline.input.sleepTime} to a non-negative integer String in seconds. Example: sleepTime = 3 waits about three seconds before the next step. 0 continues immediately.

Output and failures

Continue without a payload

Sleep has no Step Out variable and leaves the current pipeline data available to later steps. Missing, fractional, negative, or nonnumeric values fail the step. An interrupted run also fails the delay. Sleep holds execution capacity during the wait; use a scheduler or asynchronous design for long waits.
