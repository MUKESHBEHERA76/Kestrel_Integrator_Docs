Project boundary

A home for one related set of integrations

Projects help teams group the artifacts and metadata that belong together. A project has a unique name, description, creator, and stable identifier. Kestrel carries that identifier into artifact versions and execution commands, so runtime lookups do not accidentally cross into another project.
