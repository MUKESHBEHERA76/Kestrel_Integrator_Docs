Send HttpResponse

Set the HTTP status, headers, and response body for a request-driven workflow.

Configuration

Build the response

Use this step in a workflow started by a Webhook Trigger. Double-click it and provide httpStatusCode (default 200), httpStatusMessage (default OK), optional headers, and responseBody. Map values from the pipeline where the response depends on earlier steps.

httpStatusCode = 201
httpStatusMessage = Created
headerList = [{"headerName":"Content-Type","headerValue":"application/json"}]
responseBody = ${pipeline.output.createdOrder}

Pipeline and output

Return a response to the caller

headerList accepts header-name/header-value documents. If no headers are supplied, the runtime uses Content-Type: application/json. A direct pipeline expression for responseBody can resolve to a document or scalar. The step writes response code, message, headers, and body into the workflow output for the HTTP trigger response; it has no separate connector Step Out contract.

Example: createdOrder = {"id":"ORD-1042"} produces an HTTP 201 response with that body. An invalid status code fails the step. Use an Exception Handler and a second response step when failures require a different status and body.
